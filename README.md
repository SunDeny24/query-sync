# QuerySync

SQL 검증 작업을 자동화하고 시각화한 대시보드형 React 프로젝트입니다.  
매일 반복되는 검증 쿼리 실행을 수동으로 확인하지 않고, 저장된 쿼리를 기반으로 한 번의 클릭으로 실행 결과를 확인할 수 있도록 구현했습니다.

---

## 주요 기능
- 쿼리 추가 / 수정 / 삭제 / 상세보기
- 조건별 쿼리 실행 과 성공,실패 결과 표시
- 실행 결과 테이블 시각화
- 실시간 대시보드 기능

## 리팩토링 및 개선 과정

프로젝트를 실제 서비스 수준으로 고도화하고 프론트엔드 성능을 최적화하기 위해 지속적인 리팩토링을 진행하고 있습니다.

### 기존 문제점
- 무료 호스팅 환경에서 `JSON Server`의 심각한 **콜드 스타트(Cold Start)** 지연으로 인해 초기 로딩 시간이 너무 오래 걸려 정상적인 사이트 이용이 불가능했습니다.
- `fetch`와 `useState`를 이용한 수동 데이터 동기화로 인해 컴포넌트 내부 코드가 비대해지는 문제가 있었습니다.

### 해결 방안
- 로컬 Mock DB를 **Supabase(PostgreSQL)** 로 마이그레이션하여 빠르고 안정적인 클라우드 DB 환경을 구축했습니다.
- **React Query**를 도입하여 서버 상태 관리를 프론트엔드와 완벽하게 분리했습니다.

### 주요 성과
- 콜드 스타트 딜레이가 사라져 **이전보다 훨씬 빠르고 쾌적한 데이터 조회**가 가능해졌습니다.
- 비동기 로직 및 `invalidateQueries`를 통한 UI 자동 갱신을 React Query에 위임함으로써, 컴포넌트 내부의 **코드 복잡도가 대폭 감소**하고 유지보수성이 크게 향상되었습니다.
