# QuerySync

SQL 검증 작업을 자동화하고 시각화한 대시보드형 React 프로젝트입니다.  
매일 반복되는 검증 쿼리 실행을 수동으로 확인하지 않고, 저장된 쿼리를 기반으로 한 번의 클릭으로 실행 결과를 확인할 수 있도록 구현했습니다.

---

## 🔍 주요 기능
- 쿼리 추가 / 수정 / 삭제 / 상세보기
- 조건별 쿼리 실행 과 성공,실패 결과 표시
- 실행 결과 테이블 시각화
- JSON Server를 이용한 API 통신 및 Mock DB 구성

---

## 🛠 사용 기술
- React
- Vite
- Tailwind CSS
- JSON Server (Mock Data API)
- JavaScript (ES6+)
